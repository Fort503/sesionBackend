1. El DOM

JavaScript ve tu página web como un árbol de objetos llamado DOM (Document Object Model).

document.getElementById('app');

Esto permite al código encontrar y modificar cualquier elemento HTML que ves aquí.

2. Eventos

JS no solo corre una vez. Se queda esperando eventos del usuario.

boton.addEventListener('click', ...);

Cuando haces clic en "Siguiente", un evento dispara la función que cambia esta diapositiva.

3. Manipulación CSS

Podemos inyectar estilos dinámicamente sin recargar la página.

elemento.style.display = 'block';

Así es como ocultamos las otras diapositivas y mostramos esta con una animación suave.
